# File Structure
A file must exist within a subdirectory of its designated directory. The structure of these subdirectories is arbitrary. 
For example a feature could be in `data/resources/features/features/druidfeatures/wildshape.json`

```text
data/
├── resources/
│   ├── features/
│   │   ├── abilities/
│   │   ├── traitmodifications/
│   │   ├── features/
│   │   └── selectors/
│   ├── playerclasses/
│   │   ├── playerclasses/
│   │   └── playersubclasses/
│   ├── spellcasting/
│   │   ├── spells/
│   │   ├── spelllists/
│   │   └── spellselectors/
│   ├── backgrounds/
│   ├── items/
│   └── race/
├── saves
│   └── players

```
