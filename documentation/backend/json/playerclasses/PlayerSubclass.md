# Player Subclass
a subclass for a given player class

## Player Subclass JSON structure
```json
{
    "name": "subclass_name",
    "description": "subclass description"
    "feature_table": [
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        [],
        []
    ]
}
```

## Player Subclass Fields
- `name` the name of the subclass
- `description` the description for the subclass
- `feature_table` a table representing the different features that a player will have at different levels of this subclass.
